# 📊 대원푸드 사이트 경쟁력 및 UI/UX 분석 프레임워크

이 문서는 **대원푸드** 사이트가 지역 내 경쟁 업체들 사이에서 우위를 점하고 있는지, 그리고 사용자에게 최적화된 경험(UX)을 제공하는지 객관적으로 검토하기 위한 가이드입니다.

---

## 1. 🏆 시장 경쟁력 분석 (Competitive Analysis)
우리 사이트가 고객의 선택을 받을 '결정적 이유'가 있는지 확인합니다.

* **USP (Unique Selling Point) 노출:** - [ ] 첫 화면 3초 안에 '대원푸드만의 강점'(예: 30년 전통, 당일 조리, 직접 배달)이 명확히 보이는가?
* **신뢰 자산 (Trust Assets):** - [ ] 실제 조리 현장 사진, 배송 차량, 혹은 아버님의 진정성이 담긴 메시지가 포함되어 있는가?
* **경쟁사 대비 편의성:** - [ ] 경쟁사 사이트보다 메뉴 구성 확인이 더 쉽고, 전화/문의 버튼이 더 찾기 쉬운가?
* **정보의 투명성:** - [ ] 가격 정보나 상차림 구성 품목이 숨김없이 명확하게 기재되어 있는가?

---

## 🔍 2. UI/UX 5대 핵심 지표 (UX Heuristics)
사용자가 사이트 이용 중 '답답함'을 느끼지 않는지 점검합니다.

* **[직관성]** 텍스트를 다 읽지 않아도 이미지와 아이콘만으로 메뉴 성격(제사/단체)을 알 수 있는가?
* **[일관성]** 모든 페이지에서 폰트, 색상(Brand Identity), 버튼 스타일이 통일되어 신뢰감을 주는가?
* **[접근성]** 주 타겟층(40~60대)을 고려하여 폰트 크기가 충분히 크고(최소 16px), 클릭 영역이 넓은가?
* **[모바일 최적화]** 모바일 화면에서 한 손으로 모든 조작(전화 걸기, 메뉴 보기)이 가능한가?
* **[피드백]** 버튼을 눌렀을 때 '접수 완료'나 '전화 연결 중' 같은 안내가 즉각적으로 나오는가?

---

## 💰 3. 전환 최적화 (Conversion Rate Optimization)
방문자를 실제 '구매 고객'으로 전환시키는 장치들을 확인합니다.

* **CTA (Call to Action) 전략:** - [ ] '전화 상담' 버튼이 스크롤과 상관없이 항상 화면 하단에 고정(Floating)되어 있는가?
* **상담 허들 최소화:** - [ ] 별도의 로그인 없이도 성함과 연락처만으로 간편 문의가 가능한가?
* **심리적 트리거:** - [ ] "이번 달 예약 마감 임박" 혹은 "실시간 주문 현황" 등 고객의 행동을 재촉하는 요소가 있는가?
* **사회적 증거 (Social Proof):** - [ ] 최근 실제 배송된 상차림 사진이나 고객 후기가 최신순으로 업데이트되고 있는가?

---

## 🛠️ 4. 기술적 경쟁력 (Technical Audit)
개발자 관점에서 사이트의 성능과 검색 최적화를 점검합니다.

* **SEO (검색 엔진 최적화):** - [ ] '청주 단체음식', '청주 제사상' 등 핵심 키워드가 메타 태그와 본문에 잘 녹아 있는가?
* **로딩 속도:** - [ ] 음식 사진이 고화질임에도 불구하고 2초 이내에 로딩되는가? (이미지 최적화 여부)
* **안정성:** - [ ] 모든 링크가 정상 작동하며, 404 에러 페이지가 발생하지 않는가?
